# AttendEase 🎓

> No more paper. No more waiting. Just scan and go.

## The Problem
Every day in Nigerian universities, students pass paper 
sheets around for attendance. It wastes 10-15 minutes 
per class. Sheets get lost, damaged, or incomplete 
before reaching the lecturer.

## The Solution
AttendEase is a QR code based attendance system built 
for Nigerian universities.

- Lecturer creates a session → QR code generated instantly
- Students scan QR code or enter 6-digit code
- Attendance marked in seconds
- Lecturer closes session → clean digital record saved

## Features
- ✅ Real-time attendance tracking
- ✅ QR code + 6-digit code fallback
- ✅ Works on any smartphone
- ✅ Tamper-proof digital records
- ✅ Lecturer dashboard

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: Supabase
- Real-time: Supabase Realtime
